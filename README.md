## 학년 → 단원 분류, 일반 문제 / 학교 기출문제 구분
문제를 **학년 → 단원**으로 묶고, **일반 문제**와 **기출문제**를 나눠서 출제할 수 있어요. (예전에는 PDF 제목이 그대로 단원이 되어 PDF마다 따로 보였어요.)

**분류 정보 4가지**: 학년(중1·중2·중3 …) · 단원 · 구분(일반 문제 / 기출문제) · 학교·시험 이름(기출일 때).

### 1) 문제를 올릴 때 (PDF에서 문항 가져오기 · 새 시험지 등록의 "문제은행에 저장")
- 파일 이름에서 **학년·단원을 자동으로 추정해서 미리 채워요**. 예) `[강남 3구 유형공략] 4-1.입자의 운동과 물질의 상태(02) 중1 과학 [25문제] [Q].pdf` → 중1 / `4-1. 입자의 운동과 물질의 상태`. 틀리면 그 자리에서 고치세요.
- 단원 칸을 누르면 **문제은행에 이미 있는 단원 이름이 자동완성**으로 떠요 — 같은 단원은 같은 이름으로 써야 여러 PDF의 문제가 한 단원으로 모여요. 앞에 번호를 붙이면(`1. 물질의 특성`) 번호순으로 정렬돼요.
- **학교 기출문제**는 구분을 「기출문제」로 두고 **학교·시험 이름**(예: `가나중 2025 1학기 중간`)을 적으세요. 파일 이름에 학교명·`중간고사`·`기말고사`·`기출` 등이 있으면 구분과 학교·시험 이름도 자동으로 채워져요.
- 기출 한 장에는 **여러 단원이 섞여 있어서** 단원은 비워 두고, **「문항 번호별 단원」 칸**에 `1-8 물질의 상태 변화` / `9-15 여러 가지 힘`처럼 줄마다 적고 「단원 적용」을 누르면 한 번에 지정돼요(범위가 겹치면 아래 줄이 우선). 단원이 비어 있는 문항은 빨간 테두리로 표시되고, 비어 있으면 저장되지 않아요. 문항마다 직접 고칠 수도 있어요.
- 새 시험지 등록에서 기출문제를 올리면서 단원을 적지 않은 번호는 「(단원 미지정)」으로 저장돼요(시험 제목이 단원이 되지 않아요). 나중에 문제은행에서 고치세요.

### 2) 이미 문제은행에 있는 문제 정리하기 (문제은행 목록)
- 맨 위에 **구분 → 학년 → 단원** 칩이 있어서 차례로 좁혀 볼 수 있어요. 검색창은 단원·학교·문항 글자를 찾아요.
- 문항을 체크하고 **「📚 선택한 문항 분류 바꾸기」**로 학년·단원·구분·학교를 한꺼번에 바꿔요(비워둔 칸은 그대로 둬요).
- **「🤖 학년·단원 자동 채우기」**: 학년이 비어 있는 예전 문항의 **문제집 이름**에서 학년·단원을 추정해 채워요. 이름에서 학년을 못 찾으면 건드리지 않아요. 기출로 보이면 구분과 학교만 채우고 단원은 건드리지 않아요. 미리 예시를 보여주고 물어봐요.
- 학년이 안 정해진 문제는 학년 목록 맨 뒤 「미분류」에 모여요(예전과 똑같이 쓸 수 있어요).

### 3) 시험 조합 (문제 출제)
- 단원 목록이 **학년별 묶음**으로 나와요. 학년 이름을 누르면 그 학년의 모든 단원이 한 번에 선택돼요. 여러 학년의 단원을 섞어서 고를 수도 있어요.
- 맨 위 **구분**: `전체` / `일반 문제` / `기출문제만`. **기출문제만**을 고르면 같은 단원이어도 일반 문제는 빠지고 기출만 뽑혀요. (그 반대도 같아요.)
- 기출문제는 **학교·시험별로 더 좁힐 수도** 있어요(예: 다라중 기말 기출만).
- 단원 옆 숫자는 지금 구분 기준으로 센 문항 수예요(기출이 섞여 있으면 `기출 3`처럼 표시).
- 유사 시험지·**유사오답**도 같은 단원 기준이라, 학년이 있는 단원도 그대로 이어져요.

### 4) 문제 내용으로 단원 자동 추정 (🤖)
문제 글자를 읽어서, **이미 단원이 정해진 문제들과 가장 닮은 단원**을 골라줘요. 학교 기출처럼 한 파일에 여러 단원이 섞여 있을 때 번호 범위를 하나하나 쓰지 않아도 돼요.
- **어디서 쓰나요?** ① PDF에서 문항 가져오기 — 파일 카드의 「🤖 문제 내용으로 단원 추정」 ② 새 시험지 등록 — 「문항 번호별 단원」 칸 아래 버튼(추정 결과를 `1-2 식물과 에너지` 같은 줄로 채워줘요. 고쳐서 저장하세요) ③ 문제은행 목록 — 「🤖 문제 내용으로 단원 추정 (단원 미지정 문항)」(문항을 체크하면 체크한 것만).
- **무엇과 비교하나요?** 문제은행에서 **단원이 정해진 문제들**과 비교해요(같은 학년이 충분하면 그 학년 안에서만). 그래서 **먼저 단원이 분명한 일반 문제집을 올려 두는 게 중요**해요. 문제은행이 비어 있으면 추정할 수 없다고 알려줘요.
- **확신 높음 / 낮음**: 비슷함이 충분히 높고 2등과 차이가 클 때만 "확신 높음"으로 채워요. 확신이 낮은 건 비워 두고(「확신이 낮은 것도 채우기」를 켜면 1순위 후보로 채움), 추정한 칸은 **노란색**이라 한눈에 구분되고 마우스를 올리면 근거(비슷한 문항 수·유사도·다음 후보)가 보여요. 직접 고치면 노란색이 사라져요.
- 직접 쓴 단원은 덮어쓰지 않아요(「덮어쓰기」를 켜면 다시 추정).
- **한계(꼭 읽어주세요)**
  - 문제가 **글자가 아니라 그림으로 된 PDF**(예: 복사 방지가 걸린 일부 문제집)는 글자를 읽을 수 없어서 추정이 안 돼요. 글자가 안 읽히는 문항 수는 결과 안내에 나와요.
  - "다음 중 옳은 것은?"처럼 단원을 알 만한 말이 없는 문제도 억지로 추정하지 않고 비워 둬요.
  - **정확도는 비교할 문제가 얼마나 있느냐에 달려 있어요.** 직접 쓴 평가용 문제 64개(8개 단원)로 재 봤더니, 단원당 3·5·7문제로 학습했을 때 전체 정확도는 약 69% · 78% · 81%였고, "확신 높음"으로 표시된 것의 정확도는 85% · 88% · 100%(전체의 약 65%)였어요. 실제 문제집은 단원당 수십 문제가 있으니 더 나을 수 있지만, **이건 제가 쓴 문제로 잰 값이라 실제 문제와 다를 수 있어요 — 추정값은 꼭 확인하세요.**
  - 예전에 저장한 문제는 글자가 **60자까지만** 저장돼 있어서 덜 정확해요. 이번 버전부터 새로 저장하는 문제는 **240자**까지 저장해요.
  - 학년이 비어 있고 단원이 문제집 제목 그대로인 예전 문항은 "정답"으로 쓰지 않아요(제목을 단원으로 추정하는 걸 막으려고). 먼저 「🤖 학년·단원 자동 채우기」로 학년을 채워 주세요.

### 알아두세요
- 학년은 `초6`, `중1~3`, `고1~3`, `공통과학`을 인식해요. 파일 이름에 `3학년`처럼 쓰여 있으면 중학교 기준으로 `중3`으로 봐요.
- **서버(Apps Script)도 새로 배포**해야 학년·구분·학교가 저장돼요(문제은행 시트에 13~15열이 생겨요). `setup`을 한 번 더 실행하면 열 이름이 붙어요(안 해도 동작해요).
- 단원 이름은 직접 입력하는 거라 오타가 나면 다른 단원으로 갈라져요. 자동완성 목록에서 고르시면 안전해요. 갈라진 건 문제은행 목록에서 선택 → 「분류 바꾸기」로 합칠 수 있어요.

# 자동채점 시스템 (GitHub Pages 버전)

> **필요한 라이브러리(QR, PDF 읽기·만들기)는 `js/vendor/` 폴더 안에 들어 있어요.** 인터넷 주소(CDN)에 의존하지 않으니, GitHub에 올릴 때 `js/vendor` 폴더도 꼭 같이 올려주세요.

파이썬 서버 없이, GitHub Pages(정적 파일)만으로 돌아가는 버전입니다.
데이터(시험 정보·학생 점수)는 구글시트에 저장됩니다.

## 설치 순서 (처음 한 번만)

### 1) 구글시트 + Apps Script 만들기
1. 새 Google Sheet를 하나 만듭니다.
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
3. `AppsScript_Code.gs` 파일 내용 전체를 복사해서, 열린 편집기의 `Code.gs`에 그대로 붙여넣습니다 (기존 내용은 지우고 붙여넣기).
4. 상단 함수 선택 드롭다운에서 **setup** 을 선택하고 ▶ 실행 버튼을 누릅니다.
   - 처음 실행하면 권한 승인 창이 뜹니다 → 내 계정 선택 → "고급" → "이동(안전하지 않음)" → 허용.
   - 이 과정을 거치면 시트에 `Exams`, `Scores` 탭이 자동으로 생깁니다.
5. 우측 상단 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 실행할 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포를 누르면 **웹 앱 URL**이 나옵니다. 이 주소를 복사해두세요.
   - (`.../exec`로 끝나는 주소입니다.)

### 2) 프론트엔드에 서버 주소 연결하기
1. `js/config.js` 파일을 텍스트 편집기로 엽니다.
2. `API_URL` 값을 1)에서 복사한 웹 앱 URL로 바꿉니다.
   ```js
   window.APP_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/여기가바뀜/exec',
   };
   ```

### 3) GitHub Pages에 올리기
1. GitHub에서 새 저장소 생성 (Private 추천).
2. 이 폴더(모든 파일) 를 저장소에 업로드 (드래그해서 업로드하거나 git 사용).
3. 저장소 **Settings → Pages** 로 이동.
4. Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 설정 후 저장.
5. 몇 분 후 `https://사용자명.github.io/저장소이름/` 주소로 접속하면 앱이 열립니다.
   - Private 저장소에서도 GitHub Pages는 (Pro 계정이 아니면) 자동으로 공개될 수 있으니,
     정말 외부에 공개하고 싶지 않다면 GitHub Pages 대신 Netlify/Vercel의 비공개 배포를
     고려하거나, 링크를 아는 사람만 접근하게 두는 정도로 생각해주세요.

### 4) 첫 로그인
- 초기 비밀번호는 **changeme** 입니다.
- 로그인 후 반드시 **비밀번호 변경**에서 바꿔주세요.

## 사용법
기존 Flask 버전과 동일합니다: 새 시험지 등록(PDF 업로드 + 정답 입력) → QR 찍힌 PDF 다운로드 →
학생이 QR 스캔 → 이름+답 입력 → 자동채점 → 시험지 상세 페이지에서 제출 현황 확인.

## 이미 설치하신 분: 새 기능 반영하기 (문제은행 추가 업데이트)
1. `AppsScript_Code.gs` 내용을 **전부 복사**해서 Apps Script 편집기의 기존 코드를 지우고 붙여넣기 → 저장(💾)
2. 함수 선택에서 **setup** 실행 (이번 버전은 여러 번 실행해도 **기존 시험·점수 데이터가 지워지지 않아요**. `Questions` 탭만 새로 생겨요. 권한 승인 창이 또 뜨면 허용)
3. 우측 상단 **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**
   (새 배포를 만들면 주소가 바뀌니까 꼭 "수정"으로 하세요. 그러면 `config.js`는 그대로 쓰면 돼요.)
4. GitHub에는 이번 폴더의 파일들을 다시 올려서 덮어쓰기.

## 사용법
- **새 시험지 등록**: PDF를 올리면 문항 수·정답 페이지를 자동으로 찾아요. 정답칸에 숫자를 입력하면 자동으로 다음 칸으로 넘어가요(마우스 필요 없음). 정답이 그림이라 못 읽는 PDF는 원본 정답 표시를 칸 옆에 작게 띄워줘서 PDF를 따로 열 필요가 없어요. 정답·해설 페이지는 학생용 PDF에서 자동으로 뺄 수 있어요.
- **문제은행 → PDF에서 문항 가져오기**: 여러 PDF를 한 번에 올리면 문항 단위로 잘라 보여줘요. 단원(파일명으로 자동 입력)과 정답을 확인하고 저장. 잘못 잘린 건 위/아래 여백으로 다시 자르기.
- **문제은행 → 시험 조합하기**: 단원을 고르고 개수(또는 전체 문항 수)를 정하면 2단 시험지 PDF + QR + 정답이 자동 등록돼요. 이후 채점·기록은 기존과 같아요.

## 주관식(서술형) 문항이 섞인 시험
- **표시 방법**: 새 시험지 등록의 정답 칸 아래 **「주」 버튼**을 누르거나 칸에 **`-`**를 입력하면 그 문항이 **회색으로 비활성화**돼요. 답 입력에서 자동으로 건너뛰고(다음 칸으로 이동), 다시 누르면 해제돼요. 붙여넣기에서도 `-`가 주관식이에요(예: `-31425-3142`).
- **미리 추정**: 문제 글자에 "쓰시오 · 서술하시오 · 설명하시오 · 구하시오" 같은 말이 있고 ①~⑤ 보기가 없으면 주관식으로 보고 **미리 회색으로 표시**해요(틀리면 「주」를 눌러 되돌리세요).
- **학생 화면**: 주관식은 회색 줄로 나오고 **입력하지 않아요**(선생님이 따로 채점). 나머지 객관식만 다 누르면 제출돼요.
- **점수**: 주관식은 **자동 채점에서 빠지고**, 점수는 **객관식 정답 수 / 객관식 문항 수**예요(예: 5문항 중 주관식 2개 → 객관식 3문항 중 2개 정답 → 2/3). 결과 화면과 시험 상세에 "객관식 N문항만 자동 채점" 안내가 나와요. 문항마다 배점을 다르게 하거나 주관식 점수를 합산하는 기능은 아직 없어요.
- **문제은행**: 가져오기 카드와 목록에 **「주관식」 체크**가 있어요(정답 자리에 `-` 저장). 주관식이 섞인 문항으로 시험을 조합해도 자동으로 회색 처리돼요.

## 화면이 안 바뀌어 보일 때 (캐시)
- 업데이트를 올렸는데도 예전 모습 그대로면, 대부분 **브라우저나 GitHub Pages가 예전 파일을 기억하고 있어서**예요. 기존 파일을 안 지우고 덮어써서 생기는 문제는 아니에요(같은 이름이면 그냥 새 내용으로 바뀌어요).
- 확인 방법: 주소창에서 **Ctrl+Shift+R**(맥은 Cmd+Shift+R)로 강력 새로고침을 하거나, 시크릿 창으로 열어보세요.
- 이 버전부터는 모든 `css`/`js` 파일 주소 끝에 `?v=날짜시간`이 붙어있어요. GitHub에 새로 올릴 때마다 이 번호가 바뀌면서 브라우저가 자동으로 새 파일을 받아가게 했어요. **다음부터 파일을 새로 받으시면 이 문제는 저절로 없어져요.**
- (저에게 다시 요청하실 때는 신경 안 쓰셔도 돼요 — 매번 새 zip을 만들 때 이 번호를 자동으로 올려서 드릴게요.)

## 정답이 여러 개인 문항 (복수정답) — 예: 3번과 5번 모두
- **저장 형식**: 정답 번호를 이어붙여 `35`로 저장해요(주관식은 그대로 `-`). 순서·쉼표·동그라미 숫자(③⑤)로 입력해도 모두 `35`로 정리돼요.
- **새 시험지 등록 / 문제은행 가져오기 / 문제은행 목록** 공통:
  - 칸 아래 **「복」 버튼**(문제은행은 **「복수」 체크**)을 누르거나, 그 칸에서 **`+` 키**를 누르면 복수정답 칸(파란색)이 돼요.
  - 복수정답 칸에서는 **3 → 5**를 차례로 치면 `35`가 되고, 숫자를 눌러도 다음 칸으로 **자동으로 안 넘어가요**. 다음 칸으로는 **Enter 또는 Space**(방향키도 돼요).
  - 큰 숫자 표시에는 `3,5`로 떠요.
  - 한 칸에 `35`를 **붙여넣으면** 자동으로 복수정답이 되고, PDF 정답표에서 `③ ⑤`로 읽힌 것도 자동으로 복수정답 칸이 돼요.
  - 정답 붙여넣기 칸에서는 `1③⑤ 2① …`, `1. 3,5` 같은 형식도 알아봐요. (순서대로 나열한 `31425` 같은 형식은 한 문항이 한 글자라서 복수정답 구분이 안 돼요 — 번호를 붙여서 써주세요)
- **학생 화면**: 복수정답 문항에는 "복수 선택" 표시가 붙고, 번호를 **여러 개 눌러서** 고를 수 있어요(다시 누르면 취소).
- **채점**: **정답을 전부, 정확히 그 개수만큼** 골라야 정답이에요(3,5가 정답인데 3만 고르거나 3,4,5를 고르면 오답). 고른 순서는 상관없어요. 부분 점수는 없어요.
- 예전에 등록한 시험(복수정답 없음)은 그대로 동작해요.

## 문제 그림에 딸려 나오는 선 지우기 + 가운데 중간선 직접 긋기
- 원본 시험지의 칼럼 구분선 조각이 문항 그림 옆에 같이 나와서 지저분하던 것을, 그림에서 **선만 골라서 지우도록** 했어요. `<보기>` 상자·표·그래프 축처럼 지우면 안 되는 건 그대로 둬요(끝에 가로선이 붙어 있는지로 구분해요). 실제 문제집 2종에서 선이 딸려 온 문항 23개를 전부 정리하고, 상자 테두리가 그대로인 것도 확인했어요.
- **이미 문제은행에 저장돼 있는 그림**(예전 방식으로 저장돼 선이 같이 박혀 있는 것)도, **시험을 조합할 때 한 번 더 깨끗이** 해요(가로 크기와 번호 위치는 그대로, 선과 아래쪽 빈 여백만 정리).
- 대신 **앱이 모든 쪽의 정가운데에 가는 중간선을 직접 그어요** — 위에서 아래까지 쭉 이어진 한 줄이라, 진짜 시험지처럼 보여요. 해설지도 똑같아요.

## 비슷한 문제 찾기 "Failed to fetch" 해결
- 원인: 예전 시험은 PDF를 구글 드라이브 주소에서 브라우저가 직접 읽으려 해서 보안 규칙(CORS)에 막혔어요.
- 지금부터 **새로 등록하는 시험**은 문항 글자를 등록할 때 같이 저장해서, PDF를 다시 읽을 필요가 없어요.
- **예전에 등록한 시험**은 서버(Apps Script)가 PDF를 대신 받아서 내려줘요(`getExamPdf`).
- 단, 복사방지 PDF를 이미지로 바꿔서 등록한 시험은 글자가 없어서 못 찾아요.

## "등록된 시험지"가 서버 오류로 뜨던 문제
- 시험지 삭제 버튼을 넣을 때 쓴 `escapeHtml` 함수가 이 화면에서 로드되지 않아서 목록을 그리다 오류가 났어요(서버 문제가 아니었어요). 공용 파일로 옮겨서 고쳤어요.
- 앞으로 같은 실수를 막으려고, 모든 화면을 **실제 불러오는 스크립트 목록 그대로** 열어보는 점검과 "빠진 파일" 검사를 만들었어요.
- 시험지 제목에 `<`·`&` 같은 글자가 있어도 화면이 깨지지 않게 처리했어요.
- 서버 연결이 순간적으로 끊겨도 조회는 자동으로 한 번 더 시도하고, 계속 안 되면 "Apps Script를 새 버전으로 배포했는지 확인" 안내가 떠요.

## "서버에 연결할 수 없어요" 오류 방어 코드 추가
- 이 앱이 여러 번 업데이트되면서 구글시트 칸 구성이 계속 바뀌었어요. 예전에 만든 시험 데이터에 그 흔적(예전 버전의 값)이 남아있으면, 새 코드가 그걸 JSON으로 읽으려다 오류를 내고 있었어요. 이제 이런 값은 안전하게 건너뛰도록 고쳤어요.
- 여전히 특정 화면에서 이 오류가 보이면, Apps Script가 최신 버전으로 배포되어 있는지(편집기에 코드 붙여넣기 → 새 버전으로 배포) 확인해주세요.

## 새 시험지 등록 → 문제은행 자동 저장
- "새 시험지 등록" 화면에 **"이 시험 문항도 문제은행에 저장하기"** 체크박스가 생겼어요(기본으로 켜져 있어요). 저장할 때 쓸 단원명도 같이 입력하세요(시험지 이름으로 미리 채워드려요).
- 등록을 누르면 시험 등록 + 문제은행 저장이 같이 진행돼요. 난이도 점수·해설·번호 위치까지 문제은행 가져오기와 똑같이 저장돼서, 나중에 이 문항들로도 시험 조합·유사 시험지를 만들 수 있어요.
- 문제은행에 저장되는 그림은 QR이나 지우기 반영 전의 **원본 문항**이에요.

## 해설지 배치 문제 (중요 수정)
- 문단 사이가 너무 멀거나, 원본 페이지의 칼럼 구분선이 해설 옆에 그대로 남아있던 문제를 고쳤어요.
- **원인 1**: 해설 상자를 안 잘리게 넉넉히 잡다 보니, 실제 글자가 끝난 뒤의 빈 여백을 따로 잘라내지 않고 있었어요. 이제 위아래 여백을 자동으로 정리해요.
- **원인 2**: 원본 페이지의 세로 구분선이 1~2픽셀 안쪽에 있어서 지우는 로직이 못 찾고 있었어요. 이제 가장자리 쪽을 더 넓게 살펴봐서 찾아내 지워요.
- 실제 PDF로 확인했더니 해설 한 페이지에 들어가는 문항 수가 9개→11개로 늘었고, 간격도 훨씬 촘촘해졌어요.

## 다운받은 PDF가 안 열리던 문제 (중요 수정)
- 암호(복사방지) 걸린 PDF를 "새 시험지 등록"으로 올리면, 등록은 되는데 **다운받은 PDF가 실제로는 깨진 파일**이라 안 열리던 심각한 버그가 있었어요. 재현해서 확인했고, 완전히 고쳤어요.
- **원인**: 암호 걸린 PDF를 "일단 열기"만 하고 내용은 실제로 못 푸는 상태로 저장하면, 파일 속이 깨져요.
- **고친 방법**: PDF 도구를 더 안정적인 버전(`@cantoo/pdf-lib`)으로 바꾸고, 진짜로 암호를 푸는 방식으로 열도록 했어요. 그래서 원본 글자·그림이 그대로 살아있는 상태로 저장돼요. 이 방법으로도 안 열리는 아주 드문 PDF는 예전처럼 자동으로 이미지로 바꿔서 만들어요.
- 이 작업을 하면서 "새 시험지 등록"도 문제은행 조합처럼 **시험지+해설을 한 PDF로 합치고 쪽번호를 매기게** 같이 정리했어요.
- **이미 등록하신 시험 중 암호 걸린 PDF로 만든 건 다시 등록하셔야 해요** — 이미 깨진 채로 저장된 파일은 다시 만들지 않는 한 고쳐지지 않아요.

## 조합 검토 화면 그림 크게 보기
- 작아서 돋보기로 확인해야 했던 문제 그림을 **화면 너비만큼 크게** 키웠어요. 확대 안 해도 바로 읽혀요. 검토 목록과 "문항 추가" 검색 결과 둘 다 적용돼요.

## 조합 검토 화면에 문항 그림 표시
- 글로만 보여서 어떤 문항인지 알아보기 어렵다는 말씀 맞았어요. 이제 검토 목록과 "문항 추가" 검색 결과에 **작은 문제 그림**이 같이 나와요. 눌러서 크게 볼 수 있어요.

## PDF에서 워터마크·QR·이름칸 지우기 (새 시험지 등록)
- PDF를 올리면 **"✂️ 지우기 모드"** 버튼이 생겨요. 켜고 PDF 위에서 드래그하면 그 자리가 최종 PDF에서 **흰색으로 덮여서** 안 보여요. 출처 워터마크, 원래 있던 QR 코드, "이름 :" 칸 등 뭐든 지울 수 있어요.
- "족보닷컴", "교육지대" 같은 흔한 출처 표시나 "이름/성명/반/번호" 칸은 **자동으로 찾아서 후보로 보여줘요**. 눌러서 추가하면 되고, 안 보이면 직접 드래그하면 돼요.
- 표시한 자리는 목록에 쪽수와 함께 나오고, 하나씩 취소할 수 있어요. 확대·축소해도 표시는 그대로 남아요.
- 자동 찾기는 참고용이에요 — 놓치는 것도, 가끔 엉뚱한 걸 후보로 보여주는 것도 있을 수 있어서, 최종적으로는 왼쪽 PDF를 보면서 확인하시는 게 좋아요.

## 정답 입력 시 큰 숫자 표시
- 정답 칸에 숫자를 입력하면 화면 가운데에 **그 숫자가 잠깐 크게** 떠요. 작은 칸에 입력하다 실수로 다른 숫자를 누르는 걸 바로 알아챌 수 있어요.
- 새 시험지 등록, 문제은행 가져오기, 문제은행 목록 — 정답을 입력하는 모든 화면에 적용돼요. 주관식("-")을 입력하면 "주관식"이라고 표시돼요.

## 새 시험지 등록에도 오답 유사문제 (글자 유사도 기반)
- "새 시험지 등록"(PDF 통째로 올리기)으로 만든 시험은 문제은행 출처 정보가 없어서, 틀린 문항의 **단원**은 알 수 없어요. 대신 그 문항의 **글자 내용**을 다시 읽어서, 문제은행 문항들과 **내용이 비슷한 순서**로 찾아줘요(한글 2글자 단위로 겹치는 정도를 보는 방식이라, 단원 기반 매칭보다는 덜 정확해요).
- 시험 기록 관리에서 "🔍 비슷한 문제 찾기" 버튼을 누르면: 그 시험 PDF를 다시 읽어서 → 틀린 문항들의 글자를 뽑고 → 문제은행 전체와 비교해서 → 가장 비슷한 문항들로 검토 화면으로 바로 이동해요.
- 그림으로만 된 문항(글자가 없는 문항)은 비교할 글자가 없어서 못 찾아요. 문제은행에 아직 비슷한 내용이 없으면 못 찾을 수도 있어요.

## 암호(복사 방지) 걸린 PDF
- 인쇄는 되지만 복사·편집은 막아놓은(소유자 암호만 걸린) PDF를 올리면 QR 찍는 단계에서 `...PDFDocument.load\` is encrypted...` 오류가 나던 문제를 고쳤어요. 이제 이런 PDF도 그대로 올리시면 돼요.
- 사용자 암호(열 때부터 비밀번호를 물어보는 방식)가 걸린 PDF는 애초에 브라우저에서 못 열기 때문에 이 수정과 무관하게 여전히 안 돼요 — 그런 경우 암호를 먼저 푼 파일로 올려주세요.

## 문제은행·시험지 관리
- **문제은행 일괄 삭제**: 카드마다 체크박스가 있어요. "이 페이지 전체 선택" 또는 하나씩 골라서 **선택 삭제**로 한 번에 지울 수 있어요.
- **시험지 삭제**: 시험지 목록과 시험 상세 화면 양쪽에 **삭제** 버튼이 있어요. 제출 기록(학생 점수)을 같이 지울지 물어봐요.

## 시험지 + 해설지 한 PDF
- 이제 시험지와 해설지를 **한 파일**로 합쳐서 다운로드해요(QR 찍힌 시험지 뒤에 해설지가 바로 이어져요). 시험 상세 화면에 버튼이 하나로 줄었어요.
- 모든 쪽 아래에 **쪽번호(N / 전체)**가 찍혀요.
- **양면 인쇄 대비**: 시험지 쪽수가 홀수면, 해설지가 시험지 마지막 장 뒷면에 끼지 않도록 **빈 페이지를 한 장 끼워서** 해설지가 항상 새 장 앞면부터 시작하게 했어요.
- (예전에 만든 시험지는 시험지·해설지가 따로 저장되어 있어서 그대로 두 버튼이 보여요.)

## 시험 조합 후 검토 화면
- 문제은행에서 조건(단원·난이도·개수)으로 문항을 고른 뒤, 바로 PDF가 만들어지지 않고 **검토 화면**이 먼저 떠요.
- 뽑힌 문항을 하나씩 보면서 **빼기** 버튼으로 제외하거나, 검색창에서 찾아서 **추가**할 수 있어요.
- 다 확인했으면 **"최종 확정 → PDF 만들기"**를 눌러야 실제로 시험지가 만들어져요.

## 겹치지 않는 유사 시험지
- 시험 상세 화면의 **"🔁 유사 시험지 만들기"** 버튼을 누르면, 그 시험을 만들 때 썼던 단원·난이도·개수 조건이 그대로 채워진 조합 화면으로 이동해요.
- **"기존 시험과 겹치지 않게"** 체크박스가 기본으로 켜져 있어서 이미 낸 문항은 자동으로 빠지고, **체크를 해제하면 이전 문항도 다시 선택될 수 있어요** — 두 가지 모드를 직접 고르시면 돼요.
- 문제은행에서 바로 조합한 시험에만 이 버튼이 보여요(문항 출처 정보가 있어야 가능해요). PDF를 통째로 올린 시험(새 시험지 등록)에는 없어요.

## 학생 오답 기반 유사문제
- **시험 기록 관리** 화면에서 학생이 **객관식 문항을 틀렸으면** "📝 오답 유사문제 (N개)" 버튼이 떠요.
- 누르면 그 학생이 틀린 문항들의 **단원**을 자동으로 파악해서, 그 단원들에서 같은 개수만큼 새 문항을 고르는 조합 화면으로 바로 이동해요(원래 시험과 안 겹치게가 기본으로 켜져요).
- 역시 문제은행에서 조합한 시험의 기록에서만 가능해요.

## 정답·해설이 그림으로 되어 있는 PDF (추가 버그 수정)
실제로 올려주신 PDF로 테스트하다가 세 가지 버그를 더 찾아서 고쳤어요.
- **해설 페이지가 "문제 페이지"로 잘못 섞여 잡히던 문제**: 정답 번호가 전부 그림으로 되어 있어서 "정답"이라는 글자를 못 찾으면, "정답 및 해설" 같은 제목 글자를 대신 찾아서 그 뒤 페이지 전체를 해설 영역으로 확정해요.
- **문항/해설이 중간에 잘리던 문제**: 문제 본문이나 해설 문단이 그림으로 되어 있으면(글자로 안 읽히면), 그 단(칼럼)의 마지막 문항일 때 "내용이 어디까지인지" 텍스트로 못 찾아서 한두 줄만 남기고 잘렸어요. 이제 이런 경우 페이지 끝까지 넉넉하게 잡아서 안 잘려요.
- **문항마다 되풀이되는 작은 챕터 라벨("1-1. 물질의 특성" 같은 것)이 경계를 방해하던 문제**: 이 라벨이 문항 바로 밑에 살짝 걸리면, 진짜 내용이 있는 아래쪽 대신 그 라벨 위치에서 문항이 끊겨버렸어요. 이런 작은 글자는 이제 경계 판단에서 제외해요.

## 문항 사이 구분선
- 문항을 자를 때 경계를 너무 빠듯하게 잡아서, 문항 사이의 가는 구분선이 가끔 잘리던 문제를 고쳤어요. 위아래 여백을 더 넉넉하게 둬요.

## 저장 속도 (추가 수정)
- 문제은행에서 정답을 계속 고칠 때, 서버(구글시트) 쪽 코드에 **문항이 많을수록 느려지는 버그**가 있었어요 — 정답 하나만 고쳐도 시트 전체를 다시 썼거든요. 이제는 **바뀐 행만** 콕 집어서 쓰기 때문에, 문제은행에 몇 개가 저장돼 있든(2000개로 테스트) 속도가 똑같아요. 다만 자동분류처럼 한 번에 30건 넘게 바뀔 때는 예전 방식(전체 다시 쓰기)이 더 빨라서 그 경우엔 그대로 둬요.

## 정답·해설 페이지 직접 지정 (새 시험지 등록)
- 정답·해설 페이지를 자동으로 못 찾거나 잘못 찾을 때가 있어서, **왼쪽 PDF를 보고 직접 쪽 번호를 넣을 수 있게** 했어요.
- PDF를 올리면 "정답·해설 페이지" 카드에 자동 감지 결과가 나와요. 왼쪽 PDF에서 실제 정답 쪽을 확인한 뒤, 시작 쪽~끝 쪽을 입력하고 **"이 범위로 적용"**을 누르면 그 범위가 해설지 생성·학생용 PDF에서 페이지 제거에 그대로 쓰여요.

## 시험 기록 관리 (새 화면)
- 홈 → 🗂️ **시험 기록 관리**, 또는 시험 상세 화면 제출 현황 옆의 링크로 들어가요.
- **모든 시험의 제출 기록을 한 화면**에서 볼 수 있어요. 시험별 칩으로 필터, 학생 이름 검색, 정렬(최신순/오래된순/점수순/이름순), 20건씩 페이지가 돼요.
- 기록마다 **점수 수정**(정답 수·전체 문항 수를 고쳐서 저장, 자동으로 100점 환산)과 **삭제**(학생이 잘못/중복 제출했을 때)가 가능해요.

## 점수 (100점 만점 환산)
- **객관식 정답 수 ÷ 객관식 문항 수 × 100**을 반올림해서 보여줘요(예: 25문항 중 22개 → **88점**, 3문항 중 2개 → 67점). **주관식은 합산하지 않아요.**
- 학생 결과 화면에 "88점" + "객관식 25문항 중 22개 정답", 선생님 상세에는 학생별 점수와 평균·최고·최저가 나와요. 구글시트 `Scores` 탭 G열(`score100`)에도 저장돼요.

## 저장 속도
- **문제은행 목록**에서 정답·난이도·주관식을 바꿀 때 화면이 서버를 기다리지 않아요. 바로 다음 칸으로 넘어가고, 바뀐 것들을 0.6초 모아서 **한 번에** 저장해요. 화면 오른쪽 아래에 "💾 저장 중… N건 / ✓ 모두 저장됨"이 떠요. 저장이 실패하면 3초 뒤 자동으로 다시 시도하고, 저장 안 된 게 있는 채로 창을 닫으면 경고해요.
- 서버(구글시트)는 여러 문항을 고쳐도 시트를 **읽기 1번 + 쓰기 1번**만 해요(300문항 중 40개를 고쳐도 시트 접근 2번).
- **PDF에서 문항 가져오기 저장**은 3개씩 묶어서 3개 요청을 동시에 보내요(문항마다 드라이브에 이미지 파일을 만드느라 서버가 오래 걸리기 때문이에요).
- 구글 서버 자체가 한 번 응답하는 데 1~3초 걸리는 건 그대로예요. 다만 이제 입력이 그걸 기다리지 않아요.

## 왼쪽 PDF / 오른쪽 입력 화면 (새 시험지 등록 · 문제은행 가져오기)
- 왼쪽에 **PDF를 크게 띄워놓고**(쪽 이동, 확대/축소, "정답 쪽으로"), 오른쪽에 정답 입력칸이 나란히 보여요. 화면에 보이는 쪽만 그려서 쪽수가 많아도 가벼워요.
- 정답 위치를 자동으로 찾은 문항은 정답칸에 커서를 두면 **왼쪽 PDF가 그 위치로 이동하고 빨간 테두리로 표시**해줘요. 못 찾은 경우엔 정답 페이지(문제 다음 쪽)를 미리 열어둬요.
- 정답이 글자로 된 **정답표("1 ① 2 ③ …")**로 적혀 있으면 자동으로 읽어서 미리 채워요(문제 뒤쪽 페이지에서 1번부터 이어지는 표만 인정, 60% 미만이면 채우지 않아요).
- **정답 붙여넣기**: `31425` / `3 1 4 2 5` / `③①④②⑤` / `1③ 2① 3④` / `1. 3` (줄마다) / `1) ③` 형식을 알아서 해석해요. 개수가 문항 수와 다르면 경고해요. (문제은행 가져오기는 파일별로 붙여넣기 칸이 있어요)
- 문제은행 가져오기의 문항 카드는 그림을 작게(누르면 크게) 줄여서 한 화면에 여러 문항이 보여요.

## 정답 입력 화면
- **새 시험지 등록**: 화면 위에 "지금 입력할 문항"의 원본 정답 표시가 크게 고정돼서 보여요. 숫자를 치면 오른쪽 칸으로 자동 이동(Tab 불필요, ← → Backspace 가능). "📖 정답 페이지 크게 보기"로 해설 페이지 전체도 볼 수 있어요.
- **문제은행 목록**: 문항 이미지를 크게 보여주고, 저장된 해설의 맨 윗부분(정답 표시)을 문항 밑에 띄워요. 정답칸에 숫자를 치면 바로 저장되고 다음 문항으로 넘어가요. "정답이 비어있는 문항만 보기"로 빠진 것만 골라 채울 수 있어요.

## 난이도 (상·중·하)
- 문제집에 난이도 표시가 없어서, 문항의 **특징으로 난이도를 자동 추정**해요 (외부 AI 없이 앱 안에서 계산). 해설 길이, 단계별 해설 여부, 계산 문제·그림/그래프 자료 유무, 보기 개수, 문제 길이를 점수로 합쳐서 **같은 문제집 안에서 어려운 순서**로 상 30% · 중 40% · 하 30%로 나눠요(비율은 바꿀 수 있어요).
- **PDF 가져오기** 화면에서 자동으로 채워지고, 카드마다 상/중/하 버튼으로 고칠 수 있어요. 다시 누르면 미정으로 돌아가요. "난이도 일괄 지정"도 있어요.
- **문제은행 목록**: 상/중/하/미정 필터, 문항별 난이도 버튼, "🤖 난이도 미정 문항 자동 분류" 버튼(이미 정한 건 건드리지 않아요).
- **시험 조합**: "난이도 구성"에 상·중·하 개수를 넣으면 선택한 단원들에서 그 난이도별로 뽑고, 쉬운 문항부터(하→중→상) 배치해요. 개수를 안 정하면 "뽑을 난이도 범위"만 체크해서 걸러낼 수 있어요. 문항이 부족하면 어떤 난이도가 몇 개뿐인지 알려줘요.
- **문항 구성 프리셋**(시험 조합 화면): **기초(상10·중50·하40) / 기본(상20·중50·하30) / 심화(상30·중50·하20)**. 프리셋 버튼을 누르고 "전체 문항 수"를 넣으면 상·중·하 개수가 자동 계산돼요(예: 기본 20문항 → 상4·중10·하6, 심화 20문항 → 상6·중10·하4). 합이 100%가 아니게 고쳐도 그 비율로 환산해서 적용해요. **⚙ 비율 수정**에서 숫자를 고쳐 저장하면 서버에 저장돼서 어느 컴퓨터에서 열어도 같아요. 자동으로 채워진 개수를 직접 고쳐도 돼요. 어떤 난이도가 모자라면(예: 상 문항이 적을 때) 가까운 난이도로 채우고 무엇으로 채웠는지 알려줘요(체크를 끄면 부족하다고만 알려줘요).
- ⚠️ 자동 추정은 **참고용 추정**이에요. 샘플 20문항을 제가 직접 보고 매긴 난이도와 비교했을 때 15개(75%)가 일치했고, 상↔하로 정반대로 틀린 게 1개 있었어요(수식이 글자로 안 읽히는 유형은 특히 약해요). 정답률 같은 실제 데이터가 아니라서 정확한 난이도는 아니에요. 중요한 시험은 카드에서 한 번 훑어보고 고치세요.
- 예전에 저장한 문항은 난이도 점수가 없어서 자동 분류가 안 돼요. 그 PDF를 다시 가져와서 저장하세요.

## 해설지
- **문제은행 → PDF에서 문항 가져오기**: 정답·해설 페이지가 PDF에 있으면, 문항마다 해설도 자동으로 같이 잘라서 저장해요 (단·페이지를 넘어가는 해설도 이어붙여요).
- **시험 조합할 때 "해설지도 함께 만들기"**를 체크하면, 짜깁기된 문항 순서·새 번호대로 해설지 PDF가 만들어져요. 원본의 옛 번호는 지우고 왼쪽에 새 번호(빨간 원)를 붙여요.
- **새 시험지 등록**(PDF 한 개 그대로 올릴 때)은 "정답·해설 페이지 빼고 학생용 만들기"를 체크하면, 뺀 페이지들이 자동으로 해설지 PDF로 저장돼요.
- 시험지 상세 화면에서 **해설지 PDF**를 열어 인쇄할 수 있고, 정답표도 그 화면에 있어요. 학생이 답을 제출하면 채점 결과 화면에 **해설지 보기** 버튼이 나와요.
- **이미 문제은행에 저장해 둔 문항**은 해설이 같이 저장되지 않았을 수 있어요. 해설이 필요하면 그 PDF를 다시 가져와서 저장하세요.

## 알아두실 점
- PDF에 **글자로 된 문항 번호**가 있어야 자동으로 잘라요 (스캔한 이미지 PDF는 안 돼요).
- 조합된 시험지에서 원본 이미지 안의 옛 문항 번호가 보일 수 있어요. 학생이 입력할 번호는 왼쪽의 **빨간 원 번호**예요(시험지 상단에 안내 문구가 들어가요).
- 정답이 글자가 아니라 그림(①②③ 도형)인 PDF는 정답을 자동으로 읽지 않고, 이미지로만 보여드려요 — 눈으로 보고 입력하는 방식이에요.
- 브라우저 안에서 PDF를 처리하므로, 큰 PDF는 분석에 몇 초~수십 초 걸릴 수 있어요.
- 학생 답안 화면은 문항 수만 알고 **정답은 절대 내려주지 않아요**.
- 시판 문제집을 재조합해서 배포하는 건 해당 서비스 이용약관/저작권 범위를 벗어날 수 있으니 확인해서 사용해주세요.
- Apps Script 무료 할당량(하루 실행 횟수)은 학급 규모에는 충분해요.
