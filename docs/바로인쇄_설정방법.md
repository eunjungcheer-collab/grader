# 인쇄 창 없이 인쇄하기 (Edge · Chrome)

앱의 **🖨️ 인쇄** 버튼을 누르면 브라우저가 인쇄 창을 띄워요. 인쇄 창까지 없애고 **기본 프린터로 바로 나가게** 하려면, 인쇄 전용 바로가기를 하나 만들어 쓰세요.

> 이 바로가기로 연 브라우저에서는 **어떤 인쇄든 창 없이 바로 나가요.** 그래서 평소 쓰는 브라우저와 **따로** 만들어 두는 걸 추천해요.

## 1. 프린터 기본값부터 정하기 (중요)
창 없이 나가면 양면·용지·색상을 고를 수 없으니, 윈도우에서 미리 정해 둬요.
1. 설정 → Bluetooth 및 장치 → 프린터 및 스캐너 → 쓸 프린터 → **프린터 기본 설정**
2. **양면 인쇄**, 용지 **A4**, 흑백/컬러를 원하는 대로 설정 후 확인
3. 그 프린터를 **기본 프린터**로 지정

## 2. 인쇄 전용 바로가기 만들기 (Edge 기준)
1. 바탕화면 빈 곳에서 오른쪽 클릭 → 새로 만들기 → 바로 가기
2. 항목 위치에 아래를 그대로 붙여 넣기 (따옴표 포함)
   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk-printing --user-data-dir="C:\edge-print" https://eunjungcheer-collab.github.io/grader/
   ```
   (Edge가 다른 곳에 있으면 `C:\Program Files\Microsoft\Edge\Application\msedge.exe` 로 바꿔요.)
3. 이름: `자동채점 인쇄용` → 마침
4. 이 바로가기로 처음 열면 **로그인을 한 번 더** 해야 해요(따로 만든 브라우저라서).

Chrome을 쓰면 앞부분을 `"C:\Program Files\Google\Chrome\Application\chrome.exe"` 로 바꾸면 돼요.

## 3. 쓰는 법
- 인쇄 전용 바로가기로 앱을 열고, 「🖨️ 인쇄」를 누르면 **창 없이 프린터로 바로** 나가요.
- 평소 작업(파일 받기 등)은 원래 쓰던 브라우저에서 하세요.

## 알아 두세요
- 프린터가 꺼져 있거나 종이가 없으면 인쇄 작업이 대기열에 쌓여요. 윈도우 프린터 대기열에서 지울 수 있어요.
- 되돌리려면 그 바로가기를 쓰지 않으면 돼요. 평소 브라우저는 아무 영향이 없어요.
- 주소(`https://eunjungcheer-collab.github.io/grader/`)가 선생님이 쓰는 앱 주소와 다르면 그걸로 바꿔 주세요.

## 프린터를 골라서 인쇄하고 싶을 때
- 「바로 가기」로 연 창에서는 인쇄 창 없이 기본 프린터로 바로 나가요.
- 프린터를 골라야 하면 평소 쓰는 Edge나 설치한 앱 창에서 「🖨️ 인쇄」를 누르세요. 그 창들은 인쇄 창이 떠서 프린터와 설정을 고를 수 있어요.
- 바로 가기 창에서 고르고 싶으면 PDF를 받아 열고 Ctrl+Shift+P를 누르면 돼요.


## 인쇄 방식 (빠른 인쇄 / 예전 방식)

- 모든 「🖨️ 인쇄」 버튼은 기본으로 **빠른 인쇄**를 써요. PDF를 그림으로 바꾸지 않고 그대로 Edge의 PDF 뷰어에 맡겨서 더 빠르고 선명해요.
- 빠른 인쇄가 안 되는 컴퓨터(오래된 Edge 등)에서는 **자동으로 예전 방식**(쪽마다 그림으로 바꿔 인쇄)으로 인쇄돼요.
- 방식을 직접 고르려면 **데이터 관리 → 🖨️ 인쇄 방식**에서 바꿔요. 이 설정은 컴퓨터(브라우저)마다 따로 저장돼요. 학원 컴퓨터에서 쪽 설정이 달라지거나 잘림이 있으면 그 컴퓨터만 「예전 방식」으로 바꿔요.
- 빠른 인쇄는 쪽 설정(배율·여백)을 인쇄 창의 기본값으로 따라가요. 인쇄 창에서 **배율 100%(기본)**, **용지 A4**, **머리글·바닥글 끔**인지 한 번 확인해 주세요.

## 인쇄용 PDF 보관 (이 컴퓨터)

- 같은 시험지를 다시 인쇄할 때 드라이브에서 다시 받지 않도록, 최근 10개를 이 컴퓨터(브라우저)에 보관해요. 구글 드라이브·서버 용량은 쓰지 않아요.
- **데이터 관리 → 💾 인쇄용 PDF 보관**에서 켜고 끄거나 지울 수 있어요.

## 학원 컴퓨터에서 해야 하는 일

- 사이트·서버 기능은 따로 할 일이 없어요 (사이트를 열고 Ctrl+F5).
- 바로인쇄(창 없이 바로 출력)를 쓰려면 그 컴퓨터에서도 위의 `--kiosk-printing` 바로가기를 만들어요. 안 만들면 인쇄 창이 한 번 떠요.

## 교재 QR 관리

- 이미 나눠 준 교재의 시험지는 **삭제하지 말고** 「단원·정답 수정」으로 고치세요. 시험 번호가 그대로라 QR이 계속 열려요.
- 삭제하고 다시 등록했다면, 교재 등록 때 예전 QR이 **자동으로 이어져요**. 놓친 것은 **데이터 관리 → 🔗 예전 QR 이어붙이기**에서 후보를 보고 선택해 이어요 (삭제 후 30일 안에만 가능).
