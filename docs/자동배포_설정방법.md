# Apps Script 자동 배포 설정 (처음 한 번만)

설정이 끝나면 `AppsScript_Code.gs` 가 GitHub에 올라올 때마다 구글 Apps Script에 **자동으로 붙여 넣고 새 버전으로 배포**돼요. 웹앱 주소는 바뀌지 않아요.

## 준비물
컴퓨터(윈도우)에서 Node.js 설치(https://nodejs.org, LTS) → 한 번만 하면 돼요.

## 1. Apps Script API 켜기
https://script.google.com/home/usersettings 에서 **Google Apps Script API** 를 **켜기**.

## 2. 구글 로그인 정보 만들기 (컴퓨터에서)
1. 명령 프롬프트(또는 PowerShell)를 열어요.
2. `npm install -g @google/clasp` 입력
3. `clasp login` 입력 → 브라우저가 열리면 **Apps Script를 만든 구글 계정**으로 로그인·허용
4. 파일 `C:\Users\<내 이름>\.clasprc.json` 이 만들어져요. 메모장으로 열어 **내용 전체를 복사**해 둬요. (비밀번호 같은 거라 남에게 보여 주지 마세요)

## 3. 필요한 값 3가지 찾기
- **스크립트 ID**: Apps Script 편집기 → 왼쪽 ⚙️ 프로젝트 설정 → 「스크립트 ID」 복사
- **배포 ID**: 편집기 오른쪽 위 「배포」 → 「배포 관리」 → 지금 쓰는 **웹 앱** 배포의 「배포 ID」(AKfycb… 로 시작) 복사
  (웹앱 주소 `…/macros/s/<여기>/exec` 의 가운데 부분이 바로 이 값이에요)
- 위 2번에서 복사한 `.clasprc.json` 내용

## 4. GitHub에 비밀값 3개 넣기
GitHub 저장소 → Settings → Secrets and variables → Actions → **New repository secret**
| 이름 | 값 |
|---|---|
| `APPS_SCRIPT_ID` | 스크립트 ID |
| `APPS_SCRIPT_DEPLOYMENT_ID` | 배포 ID |
| `CLASPRC_JSON` | `.clasprc.json` 내용 전체 |

## 5. 확인
저장소 → Actions 탭 → **Apps Script 자동 배포** → **Run workflow** 를 눌러 한 번 실행해 보세요. 초록 체크가 뜨면 성공이에요.

## 알아 두세요
- Apps Script 프로젝트에는 **코드 파일이 하나(Code.gs)** 만 있어야 해요. 여러 개면 안전하게 멈춰요.
- 새 기능이 구글 권한(예: 메일 보내기, 드라이브)을 **새로** 요구하면 편집기에서 한 번 직접 실행해 허용해 줘야 할 수 있어요.
- 실패하면 Actions 탭에서 빨간 줄의 로그를 보고, 아니면 예전처럼 편집기에 직접 붙여 넣어도 돼요.
- `.clasprc.json` 은 구글 계정 열쇠예요. GitHub Secrets 에만 넣고 다른 곳에 올리지 마세요.
